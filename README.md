# codec-loss-lab
Streamlines multiple encodings to fastly provide material for comparison. 
Hello, thanks for reading. 
I want to make it easy to compare (and later also analyse) the effects of encoding via different settings, container, formats, and so on.
Since I'm neither a programmer or a codec-specialist, this relies heavily on LLM. Runs with Python 3.x und PyQt6 under Windows but has some issues with writing into the Videos folder. 
So if you want to test, select something inoffensive. I guess there are still a lot of cases where it crashes, a lot of bugs. And it's in german. I guess i already spent way more time thinking about changing it to english than it would ever have taken to do it... even this sentence. But maybe this is nice for someone. 
I would be interested in ideas, complaints, and anything inbetween. 
Also, I wanted to limit the length of clips to 1 minute to prevent big files and long waiting time. But it didn't made it into it, so be careful.

A second program i want to create would take the (final) video(s) and analyse the changes mathematically. Plotted nicely, this could be useful.
